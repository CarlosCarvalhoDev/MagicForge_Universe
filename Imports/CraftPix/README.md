# CraftPix — aquisição para migração pixel art

Pacotes gratuitos baixados pela sessão autenticada do navegador integrado em 28/10/2026, com autorização do usuário. Origem, SHA256, tamanho, lista de entradas e dimensões de PNGs em `inventory.json`. Regerar com `Docs/Inventory-CraftPixImports.ps1`.

Os ZIPs ficam locais e ignorados pelo Git desta pasta; não publicar ou redistribuir as fontes como biblioteca de arte. Não executar conteúdo dos arquivos. Nenhuma arte desta pasta foi integrada automaticamente ao Web ou Unity. O catálogo conta imagens (incluindo previews, sombras, variantes e folhas); **PNGCount não representa contagem de quadros de animação**.

Licença oficial: https://craftpix.net/file-licenses/ — seção Freebie Products; permite uso/modificação em jogos comerciais e distribuição do jogo. Não revender/redistribuir os arquivos como assets separados. Não enviar para geração/edição por IA. Guardar a licença aplicável junto da integração.
